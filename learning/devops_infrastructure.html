DevOps & Infrastructure

雲端與基礎建設相關的實務紀錄。

  • 部署與管理 AWS Lambda、ECS、DynamoDB、CloudFormation 等服務。
  • 使用 Kubernetes 與 VMware 相關技術，支援混合式基礎建設需求。
  • 建構雲端 IoT 方案，利用 AWS IoT Core 與 MQTT 傳輸設備數據。
  • 結合監控與指標，讓平台能提前偵測異常並快速回應。

基礎建設要點

從履歷中的實作經驗整理出來的關鍵做法。

  • 用 Infrastructure as Code 來維護部署設定，保持一致性。
  • 在 CI/CD 管線中加入自動化測試與品質檢查，降低發佈風險。
  • 搭配監控儀表板與告警，維持服務可觀測性。
  • 支援跨區團隊合作，建立正確的運維與測試流程。
