Dev Workflow & Tools

簡化團隊協作與開發流程的實務建議。

  • 建立清楚的 PR 規則與測試保護，減少錯誤程式碼進入主分支。
  • 自動化建置、測試與部署流程，讓開發回饋更快速。
  • 使用 GitHub Actions、Jenkins、Docker 等工具保持一致性。
  • 設計可復用的測試配置，降低新人上手與維護成本。

實務工具清單

由我的經驗延伸出的常用工具與做法。

  • Git / GitHub Actions：自動化版本控制與 CI 流程。
  • Jenkins：排程測試與品質門檻檢查。
  • Docker：建立一致的開發與測試環境。
  • Postman / Pytest / Playwright：API 與 UI 測試工具。
