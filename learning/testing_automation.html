Testing & Automation

測試自動化的實務經驗與設計思維。

  • 建立穩定的 End-to-End 測試框架，使用 Pytest、Playwright 與 Selenium。
  • 設計可維護的回歸測試流程，並將測試結果整合到 CI/CD 中。
  • 使用 Git 集成的測試覆蓋報告與 Jenkins 質量門檻，讓團隊掌握軟體品質。
  • 建構指標與監控訊號，提前偵測生產問題並降低 P1 事件。

自動化落地方式

  • 持續追蹤測試效率與缺陷發現率，作為品質改進依據。
